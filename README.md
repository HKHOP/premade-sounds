# Premade Sounds

موقع ثابت باللغة العربية: اكتب نصًا، واضغط «توليد» لتحويله إلى كلام عربي، واحفظ الأصوات في متصفحك.

- صوت عربي طبيعي Neural عبر [Piper](https://github.com/rhasspy/piper) (`ar_JO-kareem-medium`) يعمل داخل المتصفح ويُنزَّل مرة واحدة (~63 م.بايت) ويُخزَّن محليًا — أو صوت eSpeak NG مدمج فوري (آلي) كخيار.
- الأصوات (نص + إعدادات) تُحفظ في `localStorage`، وتُولَّد الملفات الصوتية عند الطلب.
- بلا خادم وبلا مفاتيح API: افتح `index.html` مباشرة أو انشر المجلد على أي استضافة ثابتة (مثل GitHub Pages).

## التشغيل محليًا

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا:

```bash
npx serve .
```

## GitHub Pages

ارفع المستودع إلى GitHub ثم فعّل Pages من إعدادات المستودع (المصدر: فرع `main` / الجذر). لا توجد خطوة بناء.

## الاختبار قبل النشر

راجع [AGENTS.md](AGENTS.md) — القاعدة الأولى: اختبر التوليد والتشغيل وإعادة التسمية والتكرار والحذف محليًا قبل أي نشر.

## بعد أي تعديل: تفريغ الذاكرة المؤقتة

تُقدَّم الملفات الثابتة بذاكرة مؤقتة قد تُبقي النسخ القديمة. عند أي نشر، ارفع `APP_VERSION` في `app.js`
وأبقِ `?v=<نفس الرقم>` متوافقًا في `index.html` (للملفات css/js/vendor)، ثم ادفع التغيير.
