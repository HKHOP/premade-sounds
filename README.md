# Premade Sounds

موقع ثابت باللغة العربية: اكتب نصًا، واضغط «توليد» لتحويله إلى كلام عربي، واحفظ الأصوات في متصفحك.

- صوت عربي مدمج داخل الموقع عبر [eSpeak NG](vendor/espeak-ng/LICENSE) (WASM) — يعمل على أي جهاز دون الاعتماد على أصوات النظام.
- الأصوات (نص + إعدادات السرعة والطبقة) تُحفظ في `localStorage`، وتُولَّد الملفات الصوتية عند الطلب.
- بلا خادم وبلا مفاتيح API: افتح `index.html` مباشرة أو انشر المجلد على أي استضافة ثابتة (مثل GitHub Pages).

## التشغيل محليًا

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا:

```bash
npx serve .
```

## GitHub Pages

ارفع المستودع إلى GitHub ثم فعّل Pages من إعدادات المستودع (المصدر: فرع `main` / الجذر). لا توجد خطوة بناء.
